# Personal portfolio — GitHub Pages starter

A small, responsive **HTML + CSS** site for internship and job applications. It uses no build tools, packages, or paid hosting.

## 1. Personalize it before publishing

Open `index.html` in a text editor (VS Code works well), and use **Find and Replace** to update:

| Placeholder | Replace with |
| --- | --- |
| `Your Name` | Your full name as you want it displayed to employers |
| `YOUR_USERNAME` | Your GitHub username |
| `REPLACE_FLIGHT_REPO` | Actual repository name for Flight Delay Predictor |
| `REPLACE_TRANSPORT_REPO` | Actual repository name for Transportation Inequality Explorer |
| `REPLACE_WAREHOUSE_REPO` | Actual repository name for E-Commerce Analytics Warehouse |
| `REPLACE_ANIME_REPO` | Actual repository name for Anime Recommender |
| `YOUR_EMAIL@example.com` | Your professional contact email |
| `YOUR_LINKEDIN` | Your LinkedIn public profile slug |

**Important:** Project GitHub links are **placeholders**, not verified URLs. Replace them with your real repo URLs, or remove the links for unpublished projects. Check the project descriptions and revise any details that need updating. Adjust the About section as needed.

To add your resume as a PDF: save it beside `index.html` as `resume.pdf`, then add `<a href="resume.pdf" target="_blank" rel="noopener noreferrer">Resume ↗</a>` to the navigation or hero area.

## 2. Preview it locally

Double-click `index.html` to open the site in a browser. No server or build step needed.

## 3. Publish for free with GitHub Pages

1. Sign into [GitHub](https://github.com).
2. Create a **public** repository named `YOUR_USERNAME.github.io` (replace `YOUR_USERNAME` with your actual GitHub username). Initialize it or leave it empty.
3. Upload `index.html` and `styles.css` to the repository's **root** (top level); commit the changes. You can also upload this README.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
6. Your website should appear at `https://YOUR_USERNAME.github.io/` after publication completes.

Your site URL is what you should use for **Portfolio / Personal Website** fields on job applications. Use `https://github.com/YOUR_USERNAME` for **GitHub** fields.

GitHub's official instructions: https://docs.github.com/en/pages/quickstart

## 4. Make it stronger for employers

- Aim for **3–4 polished projects** rather than a long list.
- Every repo should have a clear README: problem, data, approach, tech stack, how to run, and screenshots of outputs.
- Include live demo links when possible, and say if a live demo requires an API key or is currently offline.
- Never publish private API keys, passwords, personal datasets, or confidential work materials.
- Pin your featured projects on your GitHub profile.

You can customize colors in `styles.css`. Search for `--accent` near the top.
